# Security

Please report security problems privately through
[GitHub security advisories](https://github.com/mmukhanov/claude-pulse/security/advisories/new)
rather than in a public issue.

Worth reporting: anything that lets another local user or process read Claude Pulse's data or run
code through it, makes it touch your Claude credentials, or makes it use up your limits.

Claude Pulse is maintained in spare time; there is no guaranteed response time.
